# Library Project C++

A console-based library management project written in C++ using object-oriented programming.

## Features

- Add books and readers.
- Display all books and readers.
- Search books by title (case-insensitive for basic English characters).
- Borrow and return books.
- Each reader can borrow up to 5 different book IDs at a time.
- Reject duplicate book IDs and reader IDs.
- Validate book copy counts and basic reader/book information.

## Project structure

    Library_Project_cpp/
    |-- include/ (book.h, user.h, library.h)
    |-- src/ (book.cpp, user.cpp, library.cpp, main.cpp)
    |-- bin/ (generated by make)
    |-- obj/ (generated by make)
    |-- Makefile

## Build and run

You need a C++ compiler such as g++ and GNU Make.

    make
    make run

To remove generated files:

    make clean

## OOP design

- Book encapsulates a book's metadata and copy counts. Its methods enforce borrowing and returning rules.
- User stores reader information and the IDs of books currently borrowed. It does not own Book objects, so it must not delete them.
- Library owns the collections of books and readers and coordinates borrowing and returning.
- main.cpp handles console input/output and delegates business operations to Library.

The project currently stores data in memory. Saving/loading data from files is planned for a later stage.

## Current limitations

- No file persistence yet; data resets when the program exits.
- No due dates, fines, book deletion, or editing features yet.
- Search normalization is intended for basic text and is not full Vietnamese Unicode case folding.
